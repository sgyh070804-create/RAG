# 部署指南

## 环境

- staging：预发布环境，域名 staging.example.com。
- prod：生产环境，域名 app.example.com。

## 部署前检查

1. 代码已合并到 main，CI 全部通过。
2. 已在 staging 验证过核心流程。
3. 生产发布需要双人复核：一人操作，一人确认。

## 环境变量

```bash
export APP_ENV=prod
export DB_URL=postgres://db.internal:5432/app
export FEATURE_FLAG_NEW_UI=true
```

## 回滚

- 发布失败先回滚，再排查原因。
- 回滚命令：`./scripts/rollback.sh <版本号>`。
- 回滚后 30 分钟内在事故群同步原因。
